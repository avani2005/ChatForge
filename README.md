# ChatForge 🚀

ChatForge is an AI-powered chat application that allows users to communicate with AI and use AI to build and create things through natural language.

## ✨ Features

- 🤖 AI-powered conversations
- 💬 Interactive chat interface
- 👤 User authentication
- 🗂️ Conversation management
- 🛠️ AI-assisted building
- 🌐 Full-stack web application
- 🔐 Secure backend APIs

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB
